# C파트 방법론

RQ1: 합성 믹스 데이터로 품종 비율을 직접 학습하면, 고정 분해(B)나 분류기(A)보다
믹스견의 품종 구성을 더 잘 추정하는가.

---

## 1. 전체 구조

```
품종 라벨 사진 (Tsinghua 127종)
        │
        ▼
  동결 특징 추출기 (SIFT+BoVW / CLIP / DINOv2 / DINOv3)
        │
        ▼
  특징 공간에서 합성 믹스 생성 ─────┐
        │                          │
        ▼                          ▼
  선형 헤드 1층  ◄── 소프트 라벨(비율 벡터) 교차엔트로피
        │
        ▼
  믹스견 사진 → 사진별 품종 확률 → 개체 평균 → 시드 평균 → 채점
```

특징 추출기는 전부 동결한다. 학습하는 것은 선형 헤드 하나뿐이므로, 네 추출기의
비교가 표현의 차이만 반영한다.

## 2. 데이터

### 2.1 학습·검증 (Tsinghua Dogs)

| 항목 | 값 |
|---|---|
| 클래스 | 127종 (chinese_rural_dog, dhole, African_hunting_dog 제외) |
| 학습 | 61,592장 |
| 검증 | 5,200장 (dev 2,540 / test 2,540, `val_split_seed1.csv`) |
| 인덱스 | `index_local_v2.csv` (70,428행) |

공식 `train.lst` / `validation.lst`를 따르되, 목록에 없던 Fila Braziliero
220장은 B의 공통 분할에 맞춰 train 180 / validation 40으로 편입했다.
품종 이름은 폴더명에서 `번호-n번호-` 접두어를 제거해 정규화한다.
이미지 ID는 `폴더번호/키` 형식(예: `n000032/n112628`)으로, 세 파트가 공유한다.

### 2.2 평가 (UF 보호소 믹스견)

| 항목 | 값 |
|---|---|
| 사진 | 200장 (개체당 얼굴 패널 1 + 전신 패널 1) |
| 개체 | 100마리 (dev 20 / hold 80) |
| 정답 | `dna_UF.csv` — DNA 검사로 얻은 혈통 비율 |

dev에서 모든 설정을 고정하고, hold는 설정 확정 후 1회만 채점한다.

## 3. 특징 추출

### 3.1 SIFT + BoVW

1. 어노테이션의 몸 박스(`bodybndbox`)로 크롭하고 336×336 회색조로 변환
2. SIFT 기술자 검출
3. 학습 사진 20,000장의 기술자로 MiniBatchKMeans 코드북 학습 (K=512)
4. 각 기술자를 가장 가까운 코드워드에 배정해 히스토그램 생성
5. L1 정규화 후 제곱근 변환 (Hellinger / RootSIFT 계열)

결과는 512차원이다.

### 3.2 딥 특징

CLIP, DINOv2, DINOv3의 사전학습 가중치를 동결하고 CLS 토큰을 사용한다.
B가 추출한 샤드(`shard_*.npz`, `image_id` + `cls`, float16)를 그대로 쓰므로,
B와 C가 완전히 같은 특징 위에서 비교된다.

### 3.3 표준화

학습 데이터의 평균과 표준편차만으로 z-정규화한다.

```
z = (x - mu_train) / (sd_train + 1e-6)
```

검증·평가 통계는 쓰지 않는다(누수 방지). mu와 sd는 체크포인트에 저장해
추론 때 동일하게 적용한다.

## 4. 혼합 학습 (핵심 방법)

### 4.1 합성 믹스 생성

한 샘플을 만드는 절차는 다음과 같다.

1. 품종 수 `k ~ Uniform{2, 3, 4}`
2. 품종 `c_1..c_k`를 127종에서 비복원 추출
3. 비율 `w ~ Dirichlet(alpha=1.0)`, 길이 k
4. 각 품종에서 학습 사진 하나씩 무작위로 뽑아 그 특징을 가중합

```
x_mix = Σ_j  w_j · x_{c_j}
```

5. 정답은 비율 벡터

```
t ∈ R^127,   t[c_j] = w_j,   그 외 0
```

### 4.2 손실

소프트 라벨 교차엔트로피를 쓴다.

```
L = − Σ_b  t_b · log softmax(f(x))_b
```

정답 `t`가 고정이므로 KL 발산과 기울기가 같다. 팀 지표 정의가 KL을 쓰지 않기로
했으므로 교차엔트로피로 표기한다.

### 4.3 순종 샘플 병행

매 에폭 **순종 학습 데이터 전체**(원-핫 정답)와 **합성 믹스 20,000개**를 합쳐
하나의 배치 풀로 만든 뒤 섞어 학습한다. 순종 분류 능력과 비율 분해 능력을
함께 유지하기 위한 것이다.

### 4.4 하이퍼파라미터

| 항목 | 값 |
|---|---|
| 모델 | `nn.Linear(d, 127)` 1층, 편향 포함 |
| 최적화 | AdamW |
| 학습률 | 3e-3 (dev로 선택) |
| weight decay | 1e-4 |
| 에폭 | 20 |
| 배치 | 512 |
| 에폭당 혼합 샘플 | 20,000 |
| 혼합 품종 수 | k ∈ [2, 4] |
| Dirichlet alpha | 1.0 |
| 시드 | 1, 2, 3 |
| 에폭당 스텝 | 약 160 (총 3,200) |

학습률만 dev에서 탐색했다. 혼합 비율 분포, 품종 수 범위, 순종 대 혼합 비율은
고정값으로 두었고 탐색하지 않았다.

## 5. 대조군 (순종만 학습)

혼합 데이터를 빼고 순종 사진만으로 같은 선형 헤드를 같은 학습률·에폭·배치로
학습한다(12회). 성능 차이가 혼합 학습에서 온 것인지, 판별 학습 자체에서 온
것인지 분리하기 위한 통제다.

에폭당 약 121스텝, 총 2,420스텝으로 혼합 학습(3,200)보다 적다. 따라서 혼합
학습이 스텝 부족으로 불리했다는 해석은 성립하지 않는다.

## 6. 추론과 집계

1. 사진 하나마다 127클래스 확률을 얻는다
2. 같은 개체의 얼굴·전신 확률을 평균한다
3. 합이 1이 되도록 재정규화한다
4. 시드 1·2·3의 개체별 확률을 평균한 값을 대표 결과로 쓴다
5. 시드별 결과의 최소~최대 범위를 함께 기록한다

채점 직전, 같은 DNA 품종으로 묶인 Tsinghua 클래스의 확률을 먼저 합산한다
(예: Poodle 계열 teddy, toy_poodle, miniature_poodle, standard_poodle).
단, Top-1 지표의 예측은 합산 전 127클래스 중 최댓값을 쓴다.

## 7. 평가 지표 연결

팀 평가 지표 정의를 그대로 따른다(`evaluation_spec.md`).

- 주 지표: 원래 DNA 비율 포착@3, coverage 병기
- 보조: 재정규화 포착@3, 재정규화 분포 겹침, Top-1(Wilson 95%)
- 매핑: `breed_map.csv`의 `status=정확`만 사용
- Top-1 정답: 전체 `dna_UF.csv`에서 공동 1위를 찾은 뒤 정확 매핑 적용
- 기준선: 학습 데이터 클래스 빈도(찍기), 정답 기반 상한
- 판단: 개체 단위 짝 차이 ± 2SE가 0을 포함하면 판단 불가

## 10. 방법론상 한계와 구현 이슈

1. **딥 모델 체크포인트 미보존.** 학습 스크립트에 저장 코드가 없어 CLIP·DINOv2·
   DINOv3의 가중치가 남지 않았다. 재학습을 시도했으나 장치(GPU→CPU) 차이로
   배치 셔플 난수가 달라져 다른 모델이 되었다(CLIP 시드1: 1위 예측 일치율 88.2%,
   dev top-1 0.7516 → 0.7598). 공유된 예측·수치와 어긋나므로 재학습하지 않았다.
   예측 CSV는 모두 보존되어 있다.

2. **SIFT 특징 공간 불일치.** SIFT 추출 셀이 저장된 코드북을 그대로 쓰지 않고
   `MiniBatchKMeans(init=centers, max_iter=1).fit(centers)`로 한 번 더 학습했고,
   `random_state`가 없어 단어 공간이 재현되지 않는다. 그 결과 학습 특징과 UF
   평가 특징이 다른 공간에 놓였다. 상세와 증거는 `sift_analysis.md` 참조.

3. **선형 혼합 가정.** 특징을 비율로 가중합한 것이 실제 믹스견의 특징과 다르면,
   학습한 분해 규칙이 실제 사진으로 옮겨가지 않는다. B의 고정 분해도 같은 선형
   가정을 쓰므로 두 방법의 차이가 작게 나오는 것은 자연스럽다.

4. **도메인 차이.** 학습은 Tsinghua 순종 사진의 몸 크롭, 평가는 UF 보호소 패널
   사진이다. 배경, 해상도, 자세, 조명이 다르다.

5. **설정 탐색 부족.** 학습률 외의 혼합 설정은 탐색하지 않았다.

6. **표본 크기.** dev 18~20마리로, Top-1 95% 구간 폭이 0.3을 넘는다.
   추출기 순위를 확정적 우위로 표현하지 않는다.
