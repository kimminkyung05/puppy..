# C파트 핵심 코드

Colab에서 실행한 코드 중 재현에 꼭 필요한 부분만 모았습니다.

| 파일 | 역할 |
|---|---|
| `index_build.py` | 파일 경로 → image_id, 품종, 분할(split), 127클래스 필터 |
| `train_mix.py` | 선형 헤드 혼합 학습(합성 혼합 + 소프트 라벨 교차엔트로피), dev 예측 저장 |
| `ablation_purebred.py` | 순종만 학습한 대조군 (혼합 없이 같은 헤드) |

## 공유하지 않는 것
- 원본 이미지, 어노테이션 zip, 특징 `.npy`/`.zip`, 체크포인트 `.pt`는 용량이 커서 깃허브에 올리지 않습니다. 팀 드라이브 경로를 README에 적어 두세요.
- Drive 마운트 경로나 개인 계정 정보는 코드에 넣지 마세요.
