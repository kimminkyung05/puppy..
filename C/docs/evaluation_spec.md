# 평가 지표 정의 (dev에서 고정, hold는 설정 고정 후 1회)

## 보고 단위
- 순종견 분류: Tsinghua validation Top-1 (별도 표)
- 믹스견 비율: DNA 비율 추정 지표 (별도 표)

## 고정 설정
- 매핑: breed_map에서 status=정확만 사용. 유사는 공식 결과에서 제외.
- 개체 예측: face와 body 패널 확률을 평균.
- seed 1·2·3의 개체별 확률을 평균한 뒤 채점. seed별 최소~최대도 기록.
- 같은 DNA 품종에 묶인 Tsinghua 클래스 확률은 먼저 합산 (예: Poodle 계열 4개).
- 확률 합은 1로 유지. KL은 사용하지 않음.

## 주 지표: 원래 DNA 비율 포착@3
- captured@3(d) = Σ y(d,b), b ∈ 예측 상위 3개 품종
- y는 실제 DNA 비율(퍼센트/100)을 그대로 사용 (재정규화 없음)
- 개체 점수의 평균을 보고. coverage를 반드시 함께 제시.

## 보조 지표
- 재정규화 포착@3: 정확 매핑 DNA끼리 합 1로 재정규화 후 같은 방식 계산. 매핑 가능한 DNA가 없는 개체는 제외하고 수를 기록.
- 재정규화 분포 겹침: Σ min(predicted, truth_normalized). 0~1.
- Top-1 + coverage: 정답은 DNA 비율 최대 품종(공동 1위면 정확 매핑 클래스 합집합). 예측은 합산 전 127클래스 최대. Wilson 95% 구간 보고. 공동 1위가 모두 범위 밖이면 분모에서 제외.

## 기준선과 상한
- 찍기: train 클래스 빈도를 모든 개체에 동일 적용.
- 상한: 정확 매핑 DNA 비율 중 큰 3개 선택 시 평균.

## 반복과 비교
- 대표값: seed 확률 평균 후 채점.
- 안정성: seed별 최소~최대.
- 찍기 대비: 개체 단위 차이의 평균 ± 2SE. 0을 포함하면 판단 불가로 기록.

## 운영
- dev에서 정의, 매핑, 집계를 고정한다. 결과가 좋아 보인다고 사후 변경하지 않는다.
- hold는 설정 고정 후 한 번만 평가한다. hold 결과를 보고 매핑·지표·앙상블을 바꾸지 않는다.
