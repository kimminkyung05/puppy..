# D 담당: RQ2 단서 분석

D 파트의 17조건 단서 분석 실행 코드와 조건 정의입니다. 원본 이미지, DNA 원자료, 특징 배열, SIFT 코드북, 모델 체크포인트는 저장소에 포함하지 않습니다.

## 구성

- `configs/`: 조건 목록과 개인 환경용 경로 예시
- `notebooks/`: Colab 실행 노트북
- `scripts/`: 변형 생성·특징 추출·조건별 채점 파이프라인
- `docs/`: 실험 상태와 필요한 외부 자산

실제 입력 데이터와 결과 산출물은 팀 공유 Drive에서 관리하고, 개인 경로는 커밋하지 않습니다.
