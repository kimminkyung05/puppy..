# D 상태 요약

## 현재 공개 가능한 것

- Colab 노트북과 실행 스크립트
- 17조건 정의와 경로 예시
- 개발 집계표 3개
- 조건·seed·추출기 누락 검증 코드
- `extra_drop` 재집계 코드

## 현재 수치 상태

- 기대 매트릭스: 17조건 × 4추출기 × 3 seed = 204개
- 마지막 검증: 108개 확인, 96개 누락
- CLIP·DINOv2 변형 결과는 일부 집계됨
- DINOv3·SIFT는 원본 기준선만 확인됨
- 실제 SAM3 마스크와 최종 테스트셋 평가는 미완료
- PSNR 메타데이터는 미확보

이 문서는 개발 단계 상태 기록이며, 최종 보고 수치가 아니다.
