# D 실험 상태

## 완료 또는 확인된 부분

- D 실행 노트북과 반복 실행 가능한 Python 파이프라인 정리
- 원본 평가 결과와 조건 요약표는 팀 공유 Drive에 보관
- 17조건·3개 seed 누락 검증과 결과 집계 구조 준비
- 입력 사진·DNA 표·품종 매핑·분류기 체크포인트는 공개 저장소에서 제외

## 추가 자산이 필요한 부분

- B: DINOv3 변형 이미지용 인덱스와 최종 추출 설정
- C: SIFT 변형 추출기, 코드북, 흑백 sanity-check 특징
- SAM 담당: 실제 SAM3 체크포인트와 마스크 생성 결과
- 테스트 담당: 최종 테스트 이미지·인덱스·정답표

실제 입력과 대용량 결과는 비공개 Drive에서 관리한다.
