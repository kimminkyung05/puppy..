# D 실험 정책

- A 파트의 분류기와 seed를 고정하고 D에서는 새 분류기를 학습하지 않는다.
- 평가 이미지에는 원본, 영역, 블러, 흑백 변형과 대응 대조군을 적용한다.
- 변형 효과는 원본 점수와 대조군 점수를 함께 사용해 `extra_drop`으로 보정한다.
- 품종군 집계는 개발 단계 provisional 그룹임을 명시한다.
- 최종 테스트셋은 팀이 별도로 수집하기 전까지 D 개발 결과에 포함하지 않는다.
- 실제 SAM3 마스크와 휴리스틱 fallback 마스크를 결과에서 구분한다.
- 원본 이미지, DNA 원자료, 개인 Drive 경로, 특징 배열, 코드북, 체크포인트는 저장소에 올리지 않는다.
