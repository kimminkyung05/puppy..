- KL 발산은 쓰지 않는다.

## 2. B 쪽 세부

- **동점 처리 (FCLS):** 평균점 섞기는 대부분의 품종에 0을 준다. 0보다 큰 품종이 3개 미만이면 상위 3의 남는 자리는 이름순 품종이 채운다. 해당 마릿수는 채점 출력에 적힌다.
- **매핑에 없는 클래스:** 품종으로 합칠 때 각각 독립 품종으로 둔다(상위 3 후보에서 빼지 않는다).
- **DNA 품종 합산:** 같은 클래스 묶음으로 가는 DNA 품종이 둘 이상이면 비율을 더한다(2026-11-24 수정. 이전 B 값은 덮어쓴 값).
- **분포 겹침 예측:** 다시 나누지 않는다(예측 합 1 유지, 매핑 밖 클래스에 준 몫은 놓친 몫).
- **확인용 숫자:** 정확 매핑에서 찍기 0.088 / 0.168, 상한 0.541 / 0.970, 재정규화 겹침 찍기 0.047이 나오면 정답 · 매핑 · 품종 합치기가 A와 같다.

## 4. 계산 방법

B 예측 CSV(Drive `preds/dev/pred_RQ1-eval_uf_panels-{clip|dinov2|dinov3}-proto-r{1,2,3}[-l2].csv`)를 Colab에서 채점한다.

```bash
python scripts/provisional_score_uf.py --uf-dir "{DRIVE_DIR}/evalset/uf_draft" --eval-subset eval_uf_panels --dna "{UF_DNA}" --summary-csv results/dev_scores_final.csv
```

- 기본이 정확 매핑이다. `--with-similar`는 유사 매핑까지 넣은 참고 채점, `--reference`는 반대 매핑 Top-1과 고정 기준선 참고값을 함께 보인다.
- 출력에는 집계값만 나온다(개별 개의 DNA 값은 출력하지 않는다). 개별 DNA 표는 `/content`에만 둔다.
- 사람 기준선: `scripts/score_human_uf.py`, A · B · C · 사람 비교표: `scripts/collect_rq1_preds.py`(세 담당 예측을 공용 형식으로 모음) → `scripts/compare_rq1_dev.py`.
