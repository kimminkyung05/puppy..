# 데이터 준비

저작권·개인정보·용량 문제로 원본 이미지, UF DNA 원본 및 대용량 특징 배열은
공개 저장소에 포함하지 않는다. Tsinghua Dogs는 공식 배포처에서 내려받고,
팀 공유 드라이브의 사전 추출 특징을 사용한다.

Top-1 재현에는 `없음` 혈통까지 포함한 전체 `dna_UF.csv`, 최종
`breed_map.csv`, `split.csv`가 필요하다. 비율 평가용 `truth_UF.csv`만으로
Top-1 정답을 만들면 안 된다.

대용량 특징 파일과 12개 분류기 체크포인트의 위치 및 다운로드 방법은 팀 내부
공유 드라이브 안내에 기록한다. 공개 저장소에는 코드, 클래스 순서, 전처리
설명과 집계 결과만 포함한다.
