# A파트 최종 방법론

## 1. 데이터와 특징

Tsinghua Dogs 127클래스의 train 61,592장과 validation 5,080장을 사용했다.
B·C가 사전 추출한 동결 특징을 입력으로 사용했으며, CLIP은 512차원,
DINOv2·DINOv3는 768차원, SIFT-BoVW는 512차원이다. 모든 특징은 사진별
L2 정규화를 적용했다.

## 2. 분류기 학습

각 특징 위에 은닉층 없는 단일 선형층과 softmax로 이루어진 127클래스
분류기를 학습했다. Adam, batch size 1,024, L2 규제 `1e-4`, 최대 30 epoch,
balanced sample weight와 조기 종료를 사용했다. 특징별로 seed 1·2·3을
실행해 총 12개 분류기를 만들었다.

## 3. 개체 단위 예측

UF 개체의 face와 body 확률을 평균한 뒤 seed 1·2·3의 확률을 다시 평균해
대표 예측을 만들었다. 동일 DNA 품종에 연결되는 여러 Tsinghua 클래스는
평가 전에 합산했다. 확률 온도 보정은 적용하지 않았다.

## 4. 정답 생성

- 공식 매핑은 `status=정확`만 사용한다.
- 비율 평가는 정확 매핑 혈통의 원래 DNA 퍼센트를 유지한다.
- Top-1은 `없음` 혈통까지 포함한 전체 `dna_UF.csv`에서 개체별 최대 DNA
  비율과 공동 1위를 먼저 결정한다.
- 공동 1위 중 정확 매핑된 Tsinghua 클래스의 합집합을 정답으로 사용한다.
- 정확 매핑 가능한 공동 1위가 없으면 Top-1 분모에서 제외하며, 더 낮은
  비율의 매핑 가능 혈통을 정답으로 승격하지 않는다.

DEV에서 제외된 개체는 `UF001`, `UF076`이며 Top-1 scorable coverage는
`18/20=90%`이다.

## 5. 평가 지표

주 지표는 예측 상위 3품종이 포착한 원래 DNA 비율의 합인 captured
ancestry@3이다. 이 지표에는 DEV의 정확 매핑 원래 DNA 비율 평균인 DNA
mapping coverage `0.5665`를 함께 보고한다. 보조지표는 재정규화
captured ancestry@3, 재정규화 분포 겹침, Top-1 정확도와 Top-1 scorable
coverage이다. KL 발산은 사용하지 않는다.

찍기 기준선은 Tsinghua train 클래스 빈도로 만들고, 상한은 실제 정확 매핑
DNA 혈통 중 큰 3개를 선택해 계산한다. 비율 지표는 개체 단위 짝 차이의 평균
`±2SE`, Top-1은 Wilson 95% 신뢰구간을 사용한다.

## 6. DEV/HOLD 운영

현재 결과는 DEV 20마리에서만 계산했다. 최종 HOLD 평가는 아직 실행하지
않았으며, 정답·매핑·앙상블·평가 지표를 고정한 뒤 한 번만 수행한다.
