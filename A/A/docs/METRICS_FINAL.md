# 최종 평가 지표 정의

## 1. 태스크와 보고 단위

A는 Tsinghua Dogs 순종 이미지로 127클래스 분류기를 학습하고, 믹스견에서는
분류기의 클래스 확률을 품종 구성 비율로 해석한다.

- 순종견 분류 성능과 믹스견 비율 추정 성능은 서로 다른 표로 보고한다.
- 순종견은 Tsinghua validation Top-1 정확도로 분류기 학습 상태를 확인한다.
- 믹스견 RQ1의 주 평가는 DNA 비율 추정 지표로 수행한다.

정답 파일의 용도는 다음과 같이 구분한다.

- `dna_UF.csv`: `없음` 품종까지 포함한 전체 DNA 원본. Top-1 지배 혈통을
  결정할 때 사용한다.
- `truth_UF_ratio.csv` (`truth_UF.csv` 호환명): 정확 매핑된 혈통의 원래
  비율과 재정규화 비율을 담은 비율 평가용 파생표이다. Top-1 정답을 이
  파일에서 만들지 않는다.
- `truth_UF_top1.csv`: 전체 DNA에서 공동 1위를 먼저 결정한 뒤 정확 매핑만
  적용해 만든 개체 단위 Top-1 정답이다.

## 2. 고정 설정

- 품종 매핑: `breed_map.csv`에서 `status=정확`인 매핑만 사용한다.
- `status=유사` 매핑은 공식 결과에 포함하지 않는다.
- face와 body 사진의 클래스 확률을 평균해 개체 단위 예측을 만든다.
- seed 1·2·3의 개체별 확률을 평균한 뒤 채점한 값을 대표 결과로 사용한다.
- seed별 결과와 최소~최대 범위도 함께 기록한다.
- 동일한 DNA 품종으로 묶인 Tsinghua 클래스의 확률은 먼저 합산한다.
- 예측 확률의 합은 1로 유지한다.
- KL 발산은 사용하지 않는다.

## 3. 최종 평가 항목

### 3.1 주 지표: 원래 DNA 비율 포착 혈통 비율@3

모델이 예측한 품종 확률을 내림차순으로 정렬해 상위 3개 품종을 고른다.
개체 `d`의 점수는 해당 품종들이 실제 DNA에서 차지하는 **원래 비율**의 합이다.

```text
captured@3(d) = Σ y(d, b),  b ∈ predicted Top-3 breeds
```

- 실제 DNA 퍼센트를 100으로 나눈 값을 그대로 사용한다.
- 매핑 가능한 DNA 비율의 합이 0.83이면 1로 늘리지 않는다.
- 따라서 이 지표는 모델이 실제 전체 DNA 중 얼마를 포착했는지를 뜻한다.
- 개체 점수의 평균을 전체 결과로 보고한다.
- **DNA mapping coverage**를 함께 제시한다. 이는 개체별 정확 매핑 원래 DNA
  비율 합의 평균이며, DEV에서는 `0.5665`이다.

### 3.2 보조지표: 재정규화 포착 혈통 비율@3

`status=정확`으로 매핑된 DNA 혈통끼리 합이 1이 되도록 재정규화한 뒤
동일한 포착@3을 계산한다.

- 모델이 예측 가능한 품종 범위 안에서의 포착 능력을 보여 주는 보조지표이다.
- 실제 전체 DNA 비율로 해석하지 않는다.
- 매핑 가능한 DNA 혈통이 없는 개체는 제외하고 제외 수를 기록한다.

### 3.3 보조지표: 재정규화 분포 겹침

정확 매핑된 DNA 비율을 합 1로 재정규화하고, 모델 예측 분포와 겹치는 질량을
계산한다.

```text
overlap(d) = Σ min(predicted(d, b), truth_normalized(d, b))
```

- 0은 전혀 겹치지 않음을, 1은 완전히 겹침을 뜻한다.
- 품종을 찾았는지뿐 아니라 예측 비율의 크기까지 반영한다.
- 원래 비율 분포 겹침은 coverage를 포함한 절대 겹침 참고값으로만 보관한다.

### 3.4 분류 보조지표: Top-1 정확도 + Coverage

- 정답은 `없음` 행까지 포함한 전체 `dna_UF.csv`에서 만든다. 먼저 실제 DNA
  비율이 가장 큰 품종을 찾고, 공동 1위이면 공동 1위를 모두 유지한 다음
  `status=정확`인 Tsinghua 클래스의 합집합을 정답 집합으로 사용한다.
- 매핑되지 않은 지배 품종 대신 더 낮은 비율의 매핑 가능 품종을 정답으로
  승격하지 않는다.
- 예측: 합산 전 127클래스 확률 중 가장 큰 클래스 하나.
- 예측 클래스가 정답 집합에 들면 정답이다.
- 공동 1위 품종이 모두 정확 매핑 범위 밖이면 정확도 분모에서 제외한다.

```text
Top-1 accuracy = 정답 개 수 / 평가 가능 개 수
Coverage = 평가 가능 개 수 / 전체 개 수
```

여기서 Coverage는 **Top-1 scorable coverage**이며 `평가 가능 개 수 / 전체
개 수`로 계산한다. DEV에서는 `18/20=90%`이다. Top-1에는 Wilson 95%
신뢰구간을 함께 보고한다.

## 4. 기준선과 상한

### 찍기 기준선

사진을 보지 않고 Tsinghua train 61,592장의 클래스 빈도를 모든 개체에 동일하게
예측한 결과를 같은 지표로 채점한다.

### 상한

- 포착@3: 실제 정확 매핑 DNA 비율 중 큰 3개를 그대로 선택했을 때의 평균
- 분포 겹침: 사용한 정답 표현에서 얻을 수 있는 최대 겹침

## 5. 반복 및 비교

- 대표값: seed 1·2·3의 확률 평균을 먼저 계산한 뒤 채점
- 안정성: seed별 지표의 최소~최대 범위
- 찍기 대비 비교: 개체 단위 짝 차이의 평균 ± 2 표준오차
- `차이 ± 2SE` 구간이 0을 포함하면 `판단 불가`로 기록한다.

## 6. Dev/Hold 운영

1. dev에서 지표 정의, 정확 매핑, 집계 방법을 고정한다.
2. 결과가 크게 보인다는 이유로 지표를 사후 변경하지 않는다.
3. 새 비율 지표의 hold 평가는 설정 고정 후 한 번만 수행한다.
4. hold 결과를 본 뒤 매핑·정규화·지표·앙상블 방식을 변경하지 않는다.

## 7. 최종 보고 순서

1. 순종견 validation Top-1 표
2. 믹스견 주 지표: 원래 DNA 비율 포착@3 + DNA mapping coverage
3. 보조지표: 재정규화 포착@3, 재정규화 분포 겹침
4. 분류 보조지표: 믹스견 Top-1 + Top-1 scorable coverage
5. 찍기 기준선, 상한, seed 범위 및 통계적 판단
