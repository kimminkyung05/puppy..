# Data availability

The following assets are not redistributed in this repository:

- Tsinghua Dogs images and annotations
- UF/Reddit dog photographs and DNA result screenshots
- Source URLs and personal information
- CLIP, DINOv2, DINOv3, and SIFT precomputed feature arrays
- Large ZIP archives and local checkpoints

The Tsinghua Dogs dataset should be obtained from its official project page and used according to its terms. The mixed-dog evaluation data are restricted to the course project and should not be publicly redistributed without permission from the original sources.

Expected local evaluation files:

```text
index_eval_uf.csv
dna_UF.csv
breed_map_UF_draft.csv
```

Only aggregate, non-identifying experiment results are committed.
